# 汤圆启动器 v2.3.1(内嵌游戏版)

> 注: 文中安装包文件名以实际下载的发布版本号为准 (示例仍用 2.2.4)。

CS:GO(nosteam 1.35.4.2)一键安装启动器 —— **装完即玩**,无需任何额外配置。

## 安装

1. 下载 **整个文件夹** 共 4 个文件(`TangYuanLauncher-Setup-2.2.4.exe` + `-1.bin` + `-2.bin` + `-3.bin`,合计约 6GB,已含完整游戏),**放同一个文件夹**。
2. 双击其中的 `TangYuanLauncher-Setup-2.2.4.exe`。若出现「Windows 已保护你的电脑」,点 **更多信息 → 仍要运行**(安装包未购买商业数字签名,属正常提示)。
3. 安装器会自动选择**空间最大的非系统盘**,目录 `tangyuangame`(可自行修改,建议路径不含空格)。
4. 等待解压游戏(约 5-10 分钟,显示真实进度),完成后自动打开启动器。

> 需要磁盘空闲空间 ≥ **16GB**。

## 首次使用

- **游戏昵称**已自动生成为 `TangYuan` + 8 位随机数字,打开「配置」页即可修改。
- **游戏界面为简体中文**,开箱即用。
- **怎么进服务器**:鼠标悬停主页状态胶囊展开服务器面板,点某行的「进入」即一次性进服(不改常用设置);或「配置」页 **「自动进入服务器」** 填 `IP:端口`,点「启动游戏」自动进服;胶囊实时显示主服在线状态。
- **换主题**:主页标题栏**主题按钮**可切换深色 / 浅色 / 定时切换(默认 19:00-07:00 自动深色,时段可改)。
- **练枪**:主页标题栏**准星按钮**一键进入内置练枪地图,无需联网。
- 点主页 **「启动游戏」**,会弹一次 UAC 确认(游戏需要管理员权限运行,属 nosteam 正常机制),随后自动启动并显示状态。

## 更新

下载新版安装包直接覆盖安装即可:
- 检测到游戏已存在时**自动跳过游戏解压**,只更新启动器,秒装完成;
- 昵称、设置(`%APPDATA%\RevIniEditor\settings.json`)均保留。

### 已装旧版本(2.0.0 / 2.1.0)? 用更新包

已装过任意旧版(游戏已解压)的用户,不必重新下载 6GB 完整包,下载**单个文件** `TangYuanLauncher-Update-2.2.4.exe`(约 66MB,不含游戏)直接安装即可:
- 自动沿用原安装目录,游戏文件(14GB)**完全不动**,秒装完成;
- 昵称、已安装的优化 Loader、皮肤库等全部保留。

> ⚠ 更新包**不含游戏文件**,仅适合已装过旧版并完成游戏解压的用户。全新安装请下载完整安装包(4 个文件)。

## 卸载

控制面板 → 卸载「汤圆启动器」,将删除全部游戏文件(约 14GB)。个人配置保留在 `%APPDATA%\RevIniEditor\`,如需彻底清除请手动删除该目录。

## 常见问题

- **杀软报毒**:本程序为 Nuitka 编译的无签名独立 exe,且游戏包含 nosteam 模拟层(Loader/steamclient),个别杀软可能误报。实测 Windows Defender 未报毒;如遇误报,请添加白名单。
- **启动器打开慢(双击后 2~4 秒才出窗口)**:这是杀软实时扫描启动器文件导致的。卡巴斯基、360、火绒等杀软会在启动器**首次运行或位于新目录**时逐文件扫描 exe 和引擎组件(约 150MB,扫描需数秒),扫描完成后即恢复正常速度。可手动把启动器安装目录加入杀软「排除项/信任区」彻底消除:
  - **卡巴斯基**:设置 → 威胁和排除 → 排除项 → 添加 → 选择安装目录(如 `D:\tangyuangame`)→ 勾选「不扫描打开的文件」和「不监控程序活动」。
  - **360**:木马查杀 → 信任区 → 添加信任目录。
  - **火绒**:防护中心 → 病毒防护 → 信任区 → 添加文件夹。
  - **Windows Defender**:设置 → 病毒和威胁防护 → 排除项 → 添加文件夹。
- **连不上服务器**:先确认地址格式 `IP:端口` 无误,且服务器在线。
- **游戏目录被移动**:启动器会自动探测自己旁边的 `game\` 文件夹,移动整个 `tangyuangame` 目录后仍可正常使用。
- **游戏内文字乱码**:检查 rev.ini 中 `[Emulator] Language = schinese`(简体中文),改英文可填 `English`。

# 汤圆启动器 v2.3.0 更新说明

> 适用:完整安装包  |  2026-08-30

## ✨ 本次新增 (来自用户建议收集表)

### 🌗 深/浅/定时三态主题
- 主页标题栏新增**主题按钮**(月亮/太阳图标), 点开即可切换 **深色 / 浅色 / 定时切换**
- 定时模式默认 **19:00–07:00 自动深色**、其余时间浅色, 时段可在菜单里自定义 (支持跨午夜)
- 浅色主题沿用矢车菊蓝品牌色与矩形设计, 全部页面 (主页/配置编辑/CFG 页) 均适配
- 设置自动保存, 重启后保持

### 🖥 服务器选择直连
- 主页新增**服务器下拉框**:「跟随常用设置」(默认, 即配置页里的自动进入服务器地址) / 十人竞技 / 躲猫猫 / 「自定义 IP…」
- 十人竞技 `43.241.51.48:27015`、躲猫猫 `43.241.51.48:27016` 已内置, 也可自己添加常用服务器
- 状态胶囊跟随所选服务器显示**在线人数** (数据来自官网状态接口)
- 选中后点启动即直连, 无需再手动输 IP;启动后游戏文件自动还原

### 🎯 一键练枪启动
- 主页新增**「练枪启动」按钮**: 自动把内置练枪图 `aim_botz` 安装到游戏 maps 目录 (已装过则跳过), 然后直接进入练枪图
- 不修改任何游戏配置文件 (cfg), 与服务器直连互不干扰

### 🐛 修复
- 主页服务器状态胶囊在新版官网接口下**恒显示离线**的问题 (接口数据结构已变, 已按新结构解析)

## 📌 同批次变更
- 游戏源由 1.35.7.7 (2017 版) 切换为 **1.35.4.2** (flashtrak 重打包), 启动器的 CFG 预设/优化启动/中文语言等修改已全部迁移到新版游戏;详见 CHANGELOG

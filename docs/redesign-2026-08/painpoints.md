# 现状痛点扫描 — v2.3.1 主页（矢车菊蓝）

> 2026-08-30 · 大改战役阶段 0 产物。依据：`screenshots/current-dark.png`、`screenshots/current-light.png`（preview v1.html 渲染）+ `flet_app/main.py` / `theme.py` 走查。
> 定位：这不是否定 v2.3.1 的工程质量（收口干净、令牌齐全），而是为"换视觉语言"列出旧语言本身的表达力上限。

## P1 空间利用率低（最直观）
360 宽的窗口里，内容是约 200px 宽的居中窄柱，两侧大量死空间；主页只有 4 个元素（头像/昵称/状态胶囊/启动钮），页面显得"空"而不是"聚焦"。

## P2 关键操作可达性差
- 练枪启动、打开配置都藏在标题栏无文字图标里，新用户不可发现；
- 服务器列表藏在状态胶囊的 hover 里，唯一的进入服务器的入口靠 10px 小箭头暗示；
- 启动钮是 110px 纯图标圆（火箭），无文字标签，首次使用者需要猜。

## P3 层次与锚点单一
四个元素同权重沿中轴堆叠，没有视觉锚点；品牌色只出现在启动钮和版本徽章两处，"矢车菊蓝"没有形成氛围（背景 wash 深色下几乎不可见）。

## P4 状态表达弱
在线状态 = 8px 绿点 + "12 人"，服务器面板 hover 才出现；离线/在线的视觉差异仅一个点的颜色。

## P5 主题人格缺失
浅色主题 ≈ 深色的底色翻转，没有独立人格；两版都偏"通用后台风"，缺乏属于"汤圆启动器"的识别度。

## P6 主页无动效记忆点
唯一循环动效是在线点呼吸；启动钮、服务器胶囊、头像均无动效叙事（当然受 Flet 0.86.5 物理纪律约束，但方向稿可以在纪律内找记忆点）。

## 产品概述

CS:GO nosteam 玩家专用 Windows 桌面启动器,两个核心界面:

- **主页启动台** (360×510): 快速启动 & 玩家信息展示
- **配置编辑页** (784×600): 配置管理 & 工具修复(2026-08-08 高度由 720 缩至 600,5/6)
- **修改头像页** (784×600): 本地选图裁剪后写入游戏头像(2026-08-23 新增, 主页头像点击进入)

## 间距 & 布局

### 间距单位 (px)

- **最小**: 4px (微调)
- **小**: 8px / 10px (紧密相邻元素、卡片组 gap)
- **标准**: 12px / 14px / 16px (组内间距、卡片内边距)
- **大**: 20px / 24px (区域间距)
- **主页特例**: 36px 横向 / 48px 底部 (launcher-card padding)

### 圆角半径

> 2026-08-22 用户决策: **全面矩形化** — 窗口/卡片/按钮/输入框/标签等所有 4/6/8/16px 圆角改为直角

## 组件库

> 完整组件清单(28 个组件:用途/props/何时用/何时不用/Flet 映射)见 **`design-system.md`**。以下为关键组件速查。

### 启动按钮 (LaunchButton,主页主操作)

- 尺寸: **110×110px 圆形**,纯图标(rocket,44px),**无文字**
- 背景: 纯色 `#6495ED`(矢车菊蓝,无渐变)
- 阴影: 无彩色发光,仅极淡中性投影 `0 2px 8px rgba(0,0,0,0.35)`
- hover: 纯色加深 `#4F7FE0` + 上移 -2px + 投影 `0 4px 12px rgba(0,0,0,0.4)`
- active: 缩小 scale(0.98)
- 状态机: 点击 → 启动中(`#4F7FE0`,1.5s)→ 已启动(`#10b981` + 绿辉光 `rgba(16,185,129,0.4)`,4s)→ 复位;期间防重复点击(title 同步:启动游戏/启动中…/游戏运行中)
- 过渡: `0.3s cubic-bezier(0.4, 0, 0.2, 1)`

### 配置入口(标题栏齿轮)

- 配置按钮已从主页卡片**删除**,改为标题栏窗口控制组最左的齿轮图标(win-btn,切换至编辑页)

### 服务器监控 (ServerMonitor,主页)

- 位置: 主页启动台,昵称下方、启动按钮上方
- 形态: 胶囊(半透明底 `rgba(255,255,255,0.04)` + 细边框,圆角 pill,padding 5px 12px)
- 内容: 状态圆点(8px) + 标签 + 人数;**标签与人数同字号 15px mono、同基线对齐**
- 状态圆点: 在线=`#10b981` 绿 + 3px 浅绿外晕;离线=`#64748b` 灰
- 文案: 在线「在线 N 人」;离线「离线」(隐藏人数)
- **⚠ 数据契约(用户红线)**: 人数必须来自真实查询,禁止展示编造数字。真实实现用 A2S 查询(数据源 = rev.ini `Loader.ConnectServer` 的 IP:端口);查询失败/未配置 → 灰点「离线」,不显示人数。HTML 预览中的「12 人」仅为 UI 形态演示(注释已标注)

## 可访问性 & 最佳实践

1. **选区禁用**: `user-select: none` (标题、头像、徽章、标签、状态栏上)
2. **指针事件**: 装饰元素 `pointer-events: none`(当前无装饰光晕)
3. **边框样式**: 使用 `1px rgba()` 而非实心色,融合深色背景
4. **对比度**: 所有文字与背景对比度 >= 4.5:1
5. **省略策略**: 长文本(昵称/启动项标签)单行省略,不换行撑破布局
